DEADWOOD SIEGE

The complete wave-system, progression, unlock, edge-case and porting bible. Every wave from 1 to 200 is specified by a deterministic beat-sheet + seeded director: the skeleton is always the same (so runs feel fair and learnable), the flesh changes every run (so it never feels scripted). Rendered live from the canonical formulas in §6.

01Wave Philosophy — "Same Skeleton, Different Flesh"

You asked for waves that never repeat but always feel familiar. That is solved by splitting a wave into two layers:

  • The Beat Sheet (fixed, common thread). Archetype order, zombie-type introduction waves, boss cadence (every 10), mini-boss cadence (every 5 from 25), and the 7-beat pressure/breather rhythm are hard-coded. A player learns the language of the game: "ah, it's a Siege beat, walls up."
  • The Director Roll (variable flesh). Exact unit counts, mix ratios, elite rolls and which mutation modifier appears are rolled from a seeded RNG. New run = new seed = new flesh on the same skeleton.
Layman: the beat sheet is the chord progression of a song; the director roll is the solo. Every cover of the song sounds different, but you always recognise the song.

Seeding rules

  • Endless run seed = random per run (variation).
  • Daily Challenge seed = date hash → every player worldwide gets the identical 200-wave gauntlet that day → fair leaderboards.
  • This document's table uses the canonical reference seed 9137 so designers can quote exact waves.
  • Variance guard: any rolled count is clamped to ±15% of the reference budget so a lucky seed can never produce an impossible wave.

04Mutation Modifiers (the spice, never before W12)

Modifiers are the main "never the same twice" lever. They unlock into a pool on fixed waves (common thread) but which one fires is a seeded roll (variation). Breather waves never carry modifiers.

Stacking rules per era

  • Era II (21–50): 35% chance of 1 modifier.
  • Era III (51–100): 60% chance of 1.
  • Era IV (101–150): always 1, +20% chance of a 2nd.
  • Era V (151–200): always 1, +30% 2nd, +10% 3rd. Chaos is the point.

05The Rhythm Calendar

Pressure must breathe or players numb out. The 7-beat wheel plus boss overlays produces this repeating feel:

07Beyond Wave 200 — The Infinite Formula

After the scripted finale the director switches to pure formula so the leaderboard never ends:

infinite(n) for n > 200
budget(n)  = 580 + (n-200)*3.5 + floor((n-200)/10)*40
hp_scale(n) = 1.12^200 capped → switch to linear: hp = base * (K + 0.08*(n-200))
modifiers  = always 2, +30% chance of 3
elites     = 50% of units
bosses     = every 10, +1 extra Warlord per 50 waves past 200
archetype  = free seeded roll (no beat wheel), breather still every 7
Numeric safety: never let hp keep compounding exponentially past ~W200 or floats lose precision and crossbow damage rounds to 0 (the "immortal zombie" bug). Switch to linear + multiplier tiers as above.

10Economy Curve (why the ladder paces itself)

  • Trees / stone nodes are long-lasting with slow regen (your spec): income ≈ constant per minute, so time is the real currency.
  • Food is the throttle: swinging and dashing burn energy; farms inside walls are the only late-game source → Scavenger raids hurt exactly when they should.
  • Wave loot: each kill drops scraps (wood 60% / stone 25% / food 15% weighted) auto-collected moomoo-style; breather supply drops top up the missing type.
  • Sink curve: total T1 blueprint costs ≈ 620 W / 335 S / 65 F across all 20 — reachable by ~W40 of diligent play, so the ladder never hard-gates, only soft-paces.

11Reference GDScript (skeletons, not full impl)

wave_director.gd — beat sheet + seeded roll
# Autoload: WaveDirector — the common thread + the flesh
signal wave_started(n: int, plan: Dictionary)
signal wave_cleared(n: int)

var run_seed: int = 0
var wave: int = 0
const BEATS := ["Mix","Rush","Siege","Mix","Raid","Swarm","Breather"]

func start_run(seed_override: int = -1) -> void:
    run_seed = seed_override if seed_override >= 0 else randi()
    wave = 0; next_wave()

func next_wave() -> void:
    wave += 1
    var rng := RandomNumberGenerator.new()
    rng.seed = run_seed + wave * 7919        # flesh roll, reproducible
    var arch := "Boss" if wave % 10 == 0 else BEATS[(wave - 1) % 7]
    var plan := {
        "wave": wave,
        "arch": arch,
        "budget": budget(wave) * (0.35 if arch == "Breather" else 1.0),
        "mods": roll_mods(wave, rng),
        "mix": roll_mix(arch, wave, rng),   # clamped ±15% of reference
    }
    wave_started.emit(wave, plan)

func budget(n: int) -> float:
    if n <= 50:  return 3 + 1.6*n + 0.35 * pow(n, 1.3)
    if n <= 120: return 142 + (n-50) * 2.6
    return 324 + (n-120) * 3.2
time_crystals.gd — 2s snapshot ring buffer (30 slots = 60s)
# Ring buffer of serialized states; oldest auto-evicted.
const INTERVAL := 2.0
const SLOTS := 30            # 30 * 2s = 60s max rewind
var buf: Array[Dictionary] = []
var acc := 0.0

func _process(d: float) -> void:
    if paused or ad_open: return      # never snapshot mid-ad / mid-pause
    acc += d
    if acc >= INTERVAL:
        acc = 0.0
        buf.append(SaveState.snapshot())   # pure data, no Node refs — IDs only
        if buf.size() > SLOTS: buf.pop_front()

func rewind(seconds: int) -> void:      # 30 or 60, ad-gated, cooldown outside
    var idx := buf.size() - 1 - int(seconds / INTERVAL)
    if idx < 0: return
    fade_out()                              # hides the rebuild hitch
    World.wipe_dynamic()                    # zombies, arrows, particles
    SaveState.restore(buf[idx])
    buf = buf.slice(0, idx + 1)             # future is deleted — no redo
    fade_in()

12Edge-Case & Crash Catalog (read before you ship)

Every item: SYMPTOM → CAUSE → FIX. Grouped by subsystem.

A · Rewind / snapshot system
  • Rewind restores a zombie mid-swing and it instantly double-hits. Snapshot taken mid-attack-cooldown; cooldowns not serialized. Serialize every cooldown/attack timer per entity; on restore, clamp all "time since hit" values to ≥ 0.5s grace.
  • Crash: "Trying to release a freed object" after rewind. Structures/turrets stored Node references in the snapshot instead of integer IDs. Snapshots hold IDs + data only; restore re-creates nodes and re-links by ID.
  • Rewound run behaves differently than before (RNG desync). Global randf() state not saved. Use one seeded RandomNumberGenerator for gameplay; store its state in the snapshot.
  • Rewind during an ad callback duplicates the player. Ad SDK callback fires on the same frame as restore; wipe_dynamic skipped the player branch. Gate restore behind a restoring flag checked in _process; queue ad callbacks until flag clears.
  • Memory creeps up over a 40-minute run. Snapshot dicts retaining pooled-array references. Deep-copy into PackedArrays (float32/int16 quantized positions) — ~4KB/snapshot cap.
B · Browser / WebGL / CrazyGames platform
  • Zombies teleport across the map after alt-tab. Tab hidden stops rAF; on return, one giant delta tick. Clamp delta to 0.05s max; listen to visibilitychange → auto-pause.
  • Black screen + "context lost" on weak laptops. WebGL context dropped by driver under memory pressure. Handle webglcontextlost: show a styled "reload" card that restores last snapshot from sessionStorage.
  • Stuck keys after clicking an ad iframe. Window blur swallowed the key-up event. On window.blur, clear the entire input-action state map.
  • Ad never resolves → rewind button dead forever. Ad-blocker or SDK timeout; callback never fires. Wrap rewarded-ad call in a 12s timeout promise; on fail, toast "ad unavailable" and refund nothing.
  • Save corrupt in private browsing. localStorage throws QuotaExceeded/SecurityError in some private modes. try/catch every storage call; fall back to in-memory session-only mode with a small notice.
  • Audio silent on first load. Browser autoplay policy requires a user gesture. Unlock AudioContext on first click/keypress (the "tap to start" splash does double duty).
C · Physics & AI glitches
  • Runner phases through a thin wall at low FPS. Tunnelling: per-frame movement > wall thickness. Cap zombie speed × delta; walls ≥ 24px thick; enable continuous collision only for Runners (cheap subset).
  • Zombie vibrates/jitters in a wall corner forever. Seek vector fights collision normal; separation push adds oscillation. Unstuck timer: if displacement < 2px for 1.5s, apply a perpendicular slide nudge for 0.4s.
  • Zombies explode outward when a wall is destroyed. Depenetration: bodies overlapping the wall get pushed out simultaneously. On wall death, run one relaxation pass that re-positions overlapping zombies to nearest free grid cell before re-enabling collisions.
  • Crossbow aims at a zombie that already died (arrow wasted). Target reference held one frame past queue-free. Targets stored as IDs; validate is_instance_id_valid + alive flag each retarget tick.
  • NaN positions — zombie flies to infinity. normalize() on a zero-length vector when zombie is exactly on target. Guard: if distance < 0.001 skip movement; use safe_normalized() helper everywhere.
  • Boss knocked out of the map by pendulum. Knockback applied without boundary clamp. Clamp all entity positions to map rect every physics tick; knockback uses move_toward not position +=.
D · Wave / logic ordering
  • Wave ends while a Scavenger is mid-bite on a farm → food vanishes next wave. Event order: wave-clear fired before steal tick. Fixed tick order per frame: input → AI → combat → economy → wave-state. Wave-clear evaluated last.
  • Two players build on the same cell → one structure overlaps/ghosts. Occupancy checked then written non-atomically across two input handlers. Single BuildGrid authority: reserve cell on ghost-open, commit-or-release on place/cancel.
  • Spawn drip stalls: wave never finishes. Spawn queue waiting for a free pool slot that never frees (arrow pinned in a dead turret's queue). Pool acquire with timeout fallback allocate; wave-complete checks queue-empty AND field-empty with a 90s failsafe that force-spawns the remainder.
  • Leaderboard score jumps by billions. Score int overflowed after hp-scale switch, or kill-credit double-fired on rewind restore. int64 for score; kill-credit guarded by a per-zombie credited flag serialized in snapshots.
E · Split-screen / input
  • P2's keys move P1. Input actions read globally instead of per-device. Each Player holds a device id; keyboard P2 uses its own action set (arrows/numpad), never shared names.
  • Both players press keys, some inputs die. Hardware keyboard ghosting (3–6 key rollover on cheap boards). Ship an in-menu "key conflict test"; recommend one controller; document ghosting in the co-op tooltip.
  • Rewind in split-screen restores only P1. Snapshot taken per-player instead of globally. One global snapshot containing BOTH players + shared world; rewind is always a world event, never per-player.
F · Content / versioning
  • Old saves crash after you add a new structure. Deserialize assumes keys that don't exist in v1 saves. Versioned saves + migration chain (v1→v2→v3); every getter uses get(key, default).
  • New unlock makes an old wave trivially easy (meta stagnation). Balance drift as content grows. Keep a regression sheet: script a headless sim of waves 10/50/100/200 with baseline builds; CI-fail if win-rate shifts > 8%.

13MCP Toolkit — making the art & pipeline look way better

Layman: an MCP server is a universal USB-C port for your AI assistant: plug it in and the AI can actually open and operate another program (Figma, Godot, a browser, an image model) instead of just typing at you.
vector art

Recraft / vector-gen MCP

Recraft specialises in true SVG vector output — exactly your flat-polygon language. Generate icon/structure sets in-style, then import into Godot (rasterized crisp at 4×).

ui design

Figma MCP (or Penpot MCP)

Design HUD/panels in Figma with your palette tokens; the MCP lets the AI read frames and emit matching Godot Theme/StyleBox code — pixel-faithful UI, zero hand-tuning.

engine

Godot MCP (community)

AI drives the editor: create nodes, tweak Polygon2D points, run the scene, grab screenshots. Iterate on "does this tree read like moomoo?" in a loop instead of tab-switching.

qa

Playwright MCP

Auto-open your WebGL build in a real browser, click through waves, screenshot HUD states, capture performance traces. Catches the §12 browser bugs before players do.

concept

Image-model MCP (Flux / Replicate)

Moodboards and silhouette exploration for bosses/eras. Output is raster → use only as reference, then re-draw as vectors (or vectorize) to keep the style pure.

audio

ElevenLabs / audio MCP

Generate thwips, thuds, war-horns and UI clicks on demand; LLMs can't author audio files themselves, so this fills the gap in your Muse Spark workflow.

pipeline

GitHub MCP

AI opens issues, branches and PRs for each balance change; your wave-formula tweaks get versioned like code, not lost in chat.

style lock

Palette-token file

Not an MCP, but the glue: one style.tres + SVG style-rules doc fed to every tool above so all generated art shares fill/outline/inner-shade rules.

14Mobile Plan (small, phased, after web launch)

phase A · 0–6 wks post-launch

Mobile-web via CrazyGames app

Touch controls: left thumb virtual stick (move), right thumb aim/ghost-drag with grid-snap assist; radial build wheel replaces hotbar; UI scale ×1.4; zombie cap 60 + particles halved; optional 30 FPS battery mode. No new content — pure port.

phase B

Native Android (Godot export)

Same codebase, Google Play build: offline endless, local save, rewarded-ad crystals via store-safe SDK, controller support (BT gamepads), 120 Hz path for flagships.

phase C

iOS + cross-progression

Cloud save keyed by account; daily-seed challenge shared across web/mobile leaderboards; portrait-locked menu only, gameplay stays landscape.

  • Why phase A first: CrazyGames already ships your web build to mobile browsers — you learn touch-feel for free before spending on store compliance.
  • Touch golden rule: never require drag-and-drop precision; ghost previews snap to grid and auto-rotate to face outward. Thumbs are blunt instruments.
  • Rewind on mobile: same ring buffer works unchanged (it's pure data); the ad gate becomes the store's rewarded-video or a gem purchase.
